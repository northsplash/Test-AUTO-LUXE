# Street View Portal V4 — Updated

Google Street View has been removed from this build. Territory Command now uses the free Mapillary street-imagery integration.

See `MAPILLARY_FREE_STREET_VIEW_SETUP.md`.

Environment variable:
`VITE_MAPILLARY_ACCESS_TOKEN`

The old `VITE_GOOGLE_MAPS_API_KEY` variable is no longer used by Territory Street View.
